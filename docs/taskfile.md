# Taskfile

Build/dev/test orchestration lives in [`Taskfile.yml`](../Taskfile.yml) (+ per-OS includes under `build/<os>/Taskfile.yml`). Driven by [Task](https://taskfile.dev).

Target platform is **Windows**. macOS is supported as a dev-iteration host only.

## Discovery

Every task carries a `desc:` field. Inspect them via:

```
task --list           # user-facing tasks
task --list-all       # includes wails3 template internals
task --summary <name> # full summary for a specific task
```

Read `Taskfile.yml` directly when modifying tasks — each entry is annotated in-place.

## Conventions

- **GUI tasks**: `gui:*` (build, dev, run, package, assets). Aliases `build/dev/run/package` point to `gui:*` for wails3 template compatibility.
- **CLI tasks**: `cli:*` (build, build:dev, build:prod, dev, prod). Host-native binaries; R2 creds loaded from `.env.{dev,prod}.local`.
- **Test tasks**: `test` runs `test:helpers` (critical fixtures) first, then `test:unit`. `test:race` for race-detector runs.

## Single sources of truth

| Artefact | Source | Regenerated by |
|----------|--------|----------------|
| Version + product metadata | `internal/config/config.go` | `cmd/genversioninfo` → `build/windows/info.json` |
| App icons | `assets/baiki-{dev,prod}.ico` | `task gui:assets` (favicon + `.icns`); `wails3 generate syso` (Windows `.syso`) |
| R2 credentials | `.env.{env}.local` | injected at build time via `ldflags` |

All generated artefacts are gitignored.

## Troubleshooting

- **`appicon.png: no such file`** — a `common:generate:icons` dep slipped back in. Icons come from `assets/baiki-*.ico` only.
- **Bindings show `0 Services`** — generator must be invoked with `./...` to scan across packages. Services live at `internal/gui/services/`.
- **Dev mode fails on darwin with symbol redeclaration** — upstream wails3 alpha.74 bug in server-mode on darwin. Don't use `run:server` there; regular `gui:dev` works.
